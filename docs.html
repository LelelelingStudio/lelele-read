了了了读 · 使用与开发文档lelele Read · Documentation

一个纯净、无广告、零框架的在线阅读器。这里汇总了书库、阅读器、投稿与数据格式的说明。 A clean, ad-free, framework-free online reader. This page covers the library, reader, submissions and data formats.

1. 书库与阅读1. Library & reading

首页以胶囊分类和卡片网格组织书目，点开书进入统一读书器。内置书全部是 JSON 数据，按章按需加载；共创书库里的书统一走单页阅读入口，由 books.json 里的 dataUrl 指向内容。 The homepage organizes books with capsule categories and a card grid; all books open in the unified reader. Built-in books are JSON loaded chapter by chapter; community books share one entry page whose books.json points to a dataUrl.

2. EPUB 导入与下载2. EPUB import & download

在读书器里上传 EPUB，浏览器会当场解压并解析成统一 JSON，然后直接开始阅读；站内任何一本书都能现场打包成 EPUB 下载，也可以导出 TXT / HTML / JSON。仓库里不预生成 EPUB 文件，只有一份 JSON 数据源。 Upload an EPUB in the reader and it is unzipped and parsed into unified JSON right in the browser. Any site book can be packaged into an EPUB on the fly, or exported as TXT / HTML / JSON. No pre-generated EPUB files exist in the repository.

3. 书签、批注与阅读状态3. Bookmarks, notes & progress

每一段右侧都有高亮、书签、批注按钮；字号、中文字体、主题色、自定义背景、悬浮工具位置以及断点续读进度都会记在本机 localStorage，键名统一以 lelele_read_ 开头。悬浮工具可在布局模式下拖拽并自动避让。 Each paragraph has highlight, bookmark and note actions. Font size, Chinese font, theme color, custom background, floating tool positions and reading progress are stored locally under the lelele_read_ prefix. Floating tools can be dragged in layout mode and avoid overlapping.

4. 共创投稿规范4. Submission guidelines

投稿需提供书名、作者（数字 ID 或拼音）、一句简介，以及一个符合 BookContent 契约的 JSON 地址。内容必须是本人有权公开的作品，不含恶意脚本、广告或侵权内容；远程地址需允许跨域访问。 A submission needs a title, an author (numeric ID or pinyin), a short summary, and a JSON URL following the BookContent contract. Content must be yours to publish, free of scripts and ads; remote URLs must allow CORS.

5. 作者与后端5. Authors & backend

公开作者总表来自跨域只读接口；数字作者 ID 会自动匹配名称，拼音作者（如 luxun）直达作者主页。登录、可编辑资料与云端批注使用「了了了读」独立的 Supabase 实例，与兄弟站「了了了游」完全不共用。 The public author index comes from a cross-origin read-only API; numeric IDs resolve to names, pinyin IDs (e.g. luxun) link straight to author pages. Sign-in, editable profiles and cloud annotations use an independent Supabase instance, never shared with the sibling site.
