# 了了了读 · 了了了Read

> 探索未至之境 · 让阅读更轻

---

## 这是什么？

**了了了读** 是了了了岭工作室旗下的 **在线阅读产品**。

目标是做一个**轻量、干净、无广告**的网页阅读器，打开就能看。

---

## 规划方向

- 📖 支持常见电子书格式在线阅读
- 🤖 接入 AI 能力辅助阅读（摘要 / 翻译 / 提问）
- 🌙 暗色模式 + 护眼配色
- 📱 手机 / 平板 / 电脑全适配

> ⚠️ 产品仍在规划中，具体功能以上线版本为准。

---

## 技术栈

- 前端：纯 HTML + CSS + JavaScript（零框架）
- 部署：GitHub Pages + Cloudflare 加速
